Gapnil is an inference engine built from scratch by the Gapnil team, with no off-the-shelf inference framework underneath. The same open-source model needs almost 4 minutes in full mode on a single GPU. On Gapnil, median production generation takes 5.23 s, and 4.83 s at 720p, which is shorter than the clip itself.Gapnil 是零隙智能从零自研的推理引擎，不依赖现成的推理框架。同一个开源模型，单张显卡跑完整模式要将近 4 分钟；在 Gapnil 上，线上生成中位数 5.23 秒，720p 下 4.83 秒，比成片播放还快。

02 Self-improving · Gapnil × Singularity Escape (奇点逃逸)02 自演进 · 零隙智能 × 奇点逃逸

tuned by hand, one by one这些提速，

Gapnil and Singularity Escape built a recursive self-improvement (RSI) system together. Agents propose optimizations round after round, an independent reviewer checks each condition, and only code and lessons that pass are handed to the next round. The engine speeds itself up.零隙智能与奇点逃逸共建了一套递归自我改进（RSI）系统。智能体一轮轮提出优化，独立评审逐条把关，只有通过检验的代码和经验才传给下一轮。这是一台会自己变快的引擎。
